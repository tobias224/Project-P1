\subsection{Role-based and attribute-based access}
A role-based access control (RBAC), means that permissions regarding rights to read and edit a file is given by predefined roles.\cite{RBAC_vs._ABAC}
An organization with less than 10 employees in a working group would profit from using role-based access control (RBAC), as it is easier to implement and use.\cite{RBAC_vs._ABAC} 
An attribute-based access control refers to a combination of different attributes to handle permission and offers more control.\cite{RBAC_vs._ABAC}

\subsection{Principle of least privilege}
The principle of least privilege is fundamental regarding cloud computing and cybersecurity.\cite{PoLP} The core of the principle is to ensure that individuals only have the rights that are necessary in order to carry out their distinct function.\cite{PoLP} If the principle of least privilege is not maintained, an organization stands in risk of exposing itself to threats that can cause significant damage.\cite{PoLP}

\subsection{Microsoft SharePoint}
SharePoint is a cloud-based service by Microsoft. it is a solution for organizations to replace or modernize traditional file servers and improve document management.
 
Since SharePoint is cloud-based, employees can access shared files and documents remotely from different devices, provided they have the necessary permissions. Administrators can manage access through permission levels, allowing them to control whether users can view, edit, comment on or have full control over files and folders.

SharePoint can be used offline because SharePoint is closely integrated with OneDrive. Users can also access files offline if they have previously synchronized or downloaded them to their device. Any changes made while offline are stored locally and synchronized with SharePoint once an internet connection is restored.
