\subsection{Cloud-based file sharing}
An essential tool for organizations of all sizes are file sharing, both internally and externally. Common file sharing tools are Microsoft Sharepoint and Google Docs. Google Docs is an example of a cloud-based software as a service (SaaS). \cite{IT_Sikkerhed_i_praksis}\\ \\

\subsection{Role-based and attribute-based access}
A role-based access control (RBAC), means that permissions regarding rights to read and edit a file is given by predefined roles.\cite{RBAC_vs._ABAC}
An organization with less than 10 employees in a working group would profit from using role-based access control (RBAC), as it is easier to implement and use.\cite{RBAC_vs._ABAC} 
An attribute-based access control refers to a combination of different attributes to handle permission and offers more control.\cite{RBAC_vs._ABAC}

\subsection{Role explosion}
Role explosion is a synonym used to describe when the growth of digital roles surpasses the rise in employs. Roles referring to roles use to determine role-based access (RBAC). This happens when employs are assigned new roles to gain access to digital resources, instead of altering existing roles, so it includes customized accesses. Negative results can be an ever-expanding lack of oversight. For the Identity and Access Management employees it can make it hard-to-audit and make access hierarchies, by people having multiples accesses to the same resources, which further result in difficulties in mapping accesses, which can result in unnecessary security risks. \cite{role_explosion}.

Identity and access management is crucial when it comes to secure data and file sharing within an organization. Many organizations gives too many employees access to different files without any considerations regarding access. \cite{sikkerdigital} Seeing how a role-based access control is easier for small and medium-sized organizations, it is the obvious choice of file sharing. However, an attribute-based access control is considered more secure, since it is less vulnerable to attacks due to features such as time restrictions and more nuanced access.\cite{RBAC_vs._ABAC} It increases the risk of valuable data being accessible for cyber criminals. \cite{sikkerdigital}\\ \\

\subsection{Principle of least privilege}
The principle of least privilege is fundamental regarding cloud computing and cybersecurity.\cite{PoLP} The core of the principle is to ensure that individuals only have the rights that are necessary in order to carry out their distinct function.\cite{PoLP} If the principle of least privilege is not maintained, an organization stands in risk of exposing itself to threats that can cause significant damage.\cite{PoLP}

\subsection{Microsoft SharePoint}
 SharePoint is a cloud-based service by Microsoft. it is a solution for organizations to replace or modernize traditional file servers and improve document management.
 
Since SharePoint is cloud-based, employees can access shared files and documents remotely from different devices, provided they have the necessary permissions. Administrators can manage access through permission levels, allowing them to control whether users can view, edit, comment on or have full control over files and folders.

Microsoft also provides administrators with additional features to manage authorization at the user and organizational level. For example, administrators can restrict users from sharing files or folders with others. They can also configure time-limited access, ensuring that permissions automatically expire after a specified period.

SharePoint can be used offline because SharePoint can be synchronize with OneDrive, users can also access files offline if they have previously synchronized or downloaded them to their device. Any changes made while offline are stored locally and synchronized with SharePoint once an internet connection is restored. SharePoint's version history helps track changes and maintain previous versions of documents.

There are different types of service for sharing files securely between organizations. 
Microsoft provides SharePoint, which is a cloud-based service for administrating, saving, and sharing files in the organization between departments and also between external organizations. 

Sharepoint provides different security options to make sure the files and folders are protected against unauthorized access and data abuse. 

For authentication and identity management, SharePoint integrates with Microsoft Entra ID. It provides a secure sign-in and identity governance across cloud and on-premises environments.

\subsubsection{Attributes and roles}
In Microsoft Sharepoint, there are primarily two different ways to share a file or folder; either share it with specific people or share by using "copy link".\cite{sharepoint}\\ 

When a file or folder is shared with specific people, the person can select which people it should be shared with and their permission in regards to the file or folder.\cite{sharepoint} The permission is divided into different categories such as "can edit", "can review", "can view" and "can't download".\cite{sharepoint}\\

When a file or folder is shared by using "copy link", the sender can choose who gets access and (which features) of the access. It can either be given access to anyone with the link, people in the organization, people with existing access or give access to specific people over other people who may already have access.\cite{sharepoint}
